Introduction

HTML (HyperText Markup Language) is the standard markup language used to create and design web pages. It structures the content on the web by using a system of elements, also known as tags.

HTML Basics

An HTML document begins with a doctype declaration to define the version of HTML being used. The main structure of an HTML page includes:

  • The <html> element, which wraps the entire content.
  • The <head> section, which contains meta-information like title, character encoding, and linked resources.
  • The <body> section, which contains the content displayed on the web page, such as headings, paragraphs, and images.

Code example:

<body>
<h1>Hello World</h1>
</body>

Common HTML Tags

Here are some of the most commonly used HTML elements:

  • Headings: <h1> through <h6> represent different levels of headings.
  • Paragraph: <p> defines a block of text.
  • Anchor: <a> creates hyperlinks to other pages or external resources.
  • Image: <img> embeds an image.
  • Lists:
    • Unordered list: <ul> with <li> items.
    • Ordered list: <ol> with <li> items.
  • Containers:
    • <div> is a block-level container.
    • <span> is an inline container.

Code example:

<body>
<h1>Hello World</h1>
<h2>My first code</h2>
<p>This is an example of my first code. Somethings I use coding for are:</p>
<ul>
<li>Making Lists</li>
<li>Making Websites</li>
</ul>
</body>

Forms

HTML forms are used to collect user input. Key elements include:

  • <form>: Wraps all input fields and defines how data will be sent.
  • <input>: Used for text, checkboxes, radio buttons, etc.
  • <label>: Provides accessible labels for form controls.
  • <textarea>: For multi-line text input.
  • <button> or <input type="submit">: For form submission.

Forms typically include attributes such as action (URL where data is sent) and method (GET or POST).

Code example:

<body>
<form>
<label for="name">First Name</label>
<input id="name" type="text" name="name" placeholder="John Smith">
<label for="email">Email</label>
<input id="email" type="email" name="email" placeholder="example@gmail.com">
<label for="comments">Comments</label>
<textarea id="comments" name="comments" placeholder="Place your message here..."></label>
</form>
</body>

Semantic Elements

Semantic HTML uses meaningful tags to improve accessibility and SEO by describing the structure of the content:

  • <header>: Represents introductory content or a group of navigational links.
  • <footer>: Defines the footer for a section or document.
  • <nav>: Used for primary navigation links.
  • <article>: Represents self-contained content that can be independently reused or syndicated.
  • <section>: Defines a thematic grouping of content.
  • <aside>: Represents tangential content like sidebars.

Code example:

<body>
<header>
<nav>
<ul>
<li><a href="#making-lists">Making Lists</a></li>
<li><a href="#making-websites">Making Lists</a></li>
</ul>
</nav>
<body>
<section id="making-lists">
<h2>Making Lists</h2>
</section>
<section id="making-websites">
<h2>Making Websites</h2>
</section>
</header>
<footer>
<p>Copyright ©️Elizabeth Sosich</p>
</footer>
</body>

Best Practices

Semantic HTML uses meaningful tags to improve accessibility and SEO by describing the structure of the content:

  • Always start documents with <!DOCTYPE html> to ensure correct rendering in browsers.
  • Use semantic elements wherever possible for better structure and accessibility.
  • Keep code organized with consistent indentation and commenting.
  • Use lowercase for tags and attribute names.
  • Always include the alt attribute for images for accessibility.
  • Validate HTML code using the W3C Validator to catch syntax and structural errors.
  • Link external CSS and JavaScript files for better separation of concerns.
<head>
<link href="styles.css" rel="stylesheet" >
</head>
